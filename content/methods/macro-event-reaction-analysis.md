## 目的

イベントを「数値が強い／弱い」で終えず、事前価格から物語と価格構造が何を変えたかを再構成します。

## 手順

1. 公式発表、時刻、単位、コンセンサス、前回値を保存する。
2. 事前の政策経路、金利、ドル、金、株、信用、重要水準を記録する。
3. 実績と予想差、前回改定を分ける。
4. ヘッドラインと構成要素を確認する。
5. 2年、10年、実質金利、ブレークイーブンの初動を記録する。
6. ドル、金、広範株、信用・ボラティリティの初動を同じ窓で記録する。
7. 二次反応で何が反転・継続したか確認する。
8. 物語が成長、インフレ、政策、term premiumのどこで変わったか書く。
9. イベント前水平線、構造、Value Areaの内外を価格が受け入れたか判定する。
10. 反証と「何も変わらなかった」可能性を残す。

## 観察テンプレート

```text
Event / official source / timestamp:
Pre-event pricing and level:
Consensus / actual / revision:
Composition:
Policy implication A / B:
2y / 10y / real / breakeven:
Dollar / gold / equities / credit-vol:
First reaction / second reaction:
Narrative change:
Structure confirmation:
Contradiction / unresolved:
Reason to ignore the event:
```

## 反証

金利とドルだけが一瞬動き全て元の範囲へ戻る、信用が成長悪化を確認しない、価格がイベント前水準を再受容する場合、永続的な物語変更の説明は弱まります。

## 価格分析への戻り方

イベント中はスプレッドと価格発見で通常の水準が一時不安定になり得ます。固定時間ではなく、観察可能な流動性、構造、価格無効条件が再定義できることを待つ条件にします。
